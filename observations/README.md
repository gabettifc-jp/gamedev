# observations/

**他所の作り手が実際に動いているところの、生の記録。**

`references/` との違い：

| | 何が入るか | 出どころ |
|---|---|---|
| `references/` | 参照元の**ゲーム**の調査結果 | 読み物・ソース・wiki |
| `observations/` | 他所の**作り方**を、動いている最中に見たもの | 画面から写したログ |

## 決まり

- **生である。整形も要約も解釈も入れない。**分析は別の場所（`flow.md` `lessons.md`）に書く
- **上書きしない。追記だけ。**同じ相手でも、日が変わればファイルを分ける
- 出どころ・採り方・採った日・**誰が写したか**を先頭に書く
- **画面から写したものは「写した」と書く。**折りたたみの中身は無いと明記する
- 記号や札の意味を書くときは、**推定であることを明記する**（公表された仕様ではない）
- **取れなかったものを一覧にする。**
  「調べた中に在ったが落とした」のか「そもそも見ていない」のかを、後から言えるようにする
  （`references/README.md` の同じ決まりに合わせている）

## なぜ生を残すか

`references/README.md` に書いてある通り。

> 表は要約なので、要約に入らなかったものは消える。
> **後から「あの読み物は◯◯が薄かった」と言えるのは、生が残っているときだけ**

音ゲーと釣りゲーの調査（2026-08-20）は生を捨てた。**同じことを繰り返さない。**
