# references/

参照元のゲームの調査結果を置く。ゲームをまたいで使えるものだけ。

## 決まり

- 一本のゲームにしか効かない調査は、そのゲームのリポジトリの `research/` に置く
- 画像・音・素材は取り込まない。文章だけ
- 出どころと調べた日付を先頭に書く

## 中身

- `zombie-vital.md` … ゾンビヴァイタルの数値データと仕組み（2026-08-17）。末尾に勇なまの勇者の行動ルールの追記あり
- `incremental.md` … インクリメンタルの調査（2026-08-18）。プレステージ通貨の式の四種類、パークの三つの型、波の長さ
