# references/

参照元のゲームの調査結果を置く。ゲームをまたいで使えるものだけ。

## 決まり

- 一本のゲームにしか効かない調査は、そのゲームのリポジトリの `research/` に置く
- 画像・音・素材は取り込まない。文章だけ
- 出どころと調べた日付を先頭に書く
- **URL を必ず残す。**名前だけでは、後から開けない。
  `node tools/check-refs.mjs` が開くかどうかを確かめる

> **いま在る二本（`incremental.md` `zombie-vital.md`）には URL が一つも無い。**
> 出どころは名前で書いてある（「Kongregate の記事」など）が、**どれのことか分からない。**
> 調べ直すときは URL から入れ直す。
- **ジャンルシートを作るときは、その下に生の記録を必ず置く。**
  表は要約なので、要約に入らなかったものは消える。
  **後から「あの読み物は◯◯が薄かった」と言えるのは、生が残っているときだけ**

> **音ゲーと釣りゲーは、これを飛ばした（2026-08-20）。**
> 表だけ作って生を捨てたので、
> **「調べた中に在ったが落とした」のか「そもそも読んでいない」のかが確かめられない。**
> インクリメンタルは二段あるので確かめられる。**同じ日に作った二枚で、片方だけ検算できない。**

## 中身

- `zombie-vital.md` … ゾンビヴァイタルの数値データと仕組み（2026-08-17）。末尾に勇なまの勇者の行動ルールの追記あり
- `incremental.md` … インクリメンタルの調査（2026-08-18）。プレステージ通貨の式の四種類、パークの三つの型、波の長さ。**URL が無い**
- `rhythm.md` … 音ゲーの調査（2026-08-20・`genre-research` が集めた）。1184行・URL 77件。1996年〜2026年
- `incremental-2026-08-20.md` … インクリメンタルの調査（2026-08-20・同上）。1322行・URL 51件。<br>
  **`incremental.md`（2026-08-18）とは別に置いてある。**突き合わせが済むまで、どちらも消さない
- `mitame.md` … 「ゲームの見た目」の調査（2026-08-21・`genre-research` が集めた）。40件。<br>
  ジャンルではなく題。分野はジャンル用の七つではなく、値／パレット／読みやすさ／密度／
  画面の重み付け／動き／少ない手数／遊んだ人の文句 の**八つ**。<br>
  末尾に「読めなかった／開けなかった出どころ」の一覧を持つ
- `playtest.md` … 「テストプレイ」の調査（2026-08-21・`genre-research` が集めた）。**39件。**<br>
  ジャンルではなく題。渡した分野はジャンル用の七つではなく、規模と時機／何を測るか／何を聞くか／
  見ているあいだ何をするか／出た声をどう扱うか／機械にやらせるテストプレイ／間違えた話 の**七つ**。<br>
  **この枠には五つの文句が返っている。**落とした表（`templates/playtest.md`）は切り直してある<br>
  末尾に「開けなかったもの」の一覧と、**PDF をローカルに落として `Read` で読む手順**の注記を持つ<br>
  **一件（note.com の404）は、本文を開いていないので出どころの並びから落とした**
  （「開いて中身を見ていない URL は書かない」）
