# 06 画面

**B. 画面の設計の問いは、ここが正本。**flow.md 段階3のBは、この表を指している。

| 問い | 答え |
|---|---|
| **画面は何種類あるか。**それぞれ何をする画面か | |
| **画面はどう行き来するか。**どこからどこへ、何を押すと移るか | |
| **一番よく見る画面には、何がどこに置いてあるか。**上・下・左・右・中央に、それぞれ何があるか | |
| 盤面があるなら、**一マスの大きさと、縦横のマス数** | |
| キャラや物の大きさは、マスに対して何倍か | |
| **常に見えていなければならない数値は何か**（所持金、残量、進み具合） | |
| 色は何段階使うか。何で色が変わるか | |
| 参考にする画面があるなら、**実物を見て数字で書く**（「これを見て似せて」ではなく） | |
