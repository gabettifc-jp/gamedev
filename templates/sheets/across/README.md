# templates/sheets/across/

**横断シート。ジャンルをまたいで同じ相場になるものを持つ。**

ジャンルシート（`genre/`）は「そのジャンルで既に解かれている問題」を持つ。
**それとは別に、どのジャンルでも同じ答えになる相場が在る。**
見た目・音・入力の遅れなどがこれにあたる。

**書式はジャンルシートと同じ**（`genre/README.md` が正本）。違いは二つだけ。

- **配られる条件が無い。**ジャンルを書いたかどうかに関わらず、常に配られる
- **「そのジャンル固有の問い」の部にあたるものが無い。**横断なので固有ではない

## なぜ分けたか

**ジャンルシートに置くと、ジャンルの数だけ同じことを書くことになる。**
「明度を先に決める」も「文字と背景の対比は 4.5:1」も、音ゲーでも釣りでも同じ。
