# 08 入出力

**C. 入出力の設計の問いは、ここが正本。**flow.md 段階3のCは、この表を指している。

| 問い | 答え | 根拠 |
|---|---|---|
| **入力は何種類あるか**（押す、長押し、ドラッグ、キー） | | |
| **何を押すと何が起きるか。**操作の一覧 | | |
| 待ち時間や演出のあいだ、操作を受け付けるか | | |
| **絶対に止めてはいけない操作はどれか**（頻度の高いものは止めると累積で効く） | | |
| 間違えて押したときに取り返しはつくか | | |
| **判定や当たりの外で入力したら、何が起きるか** | | |
| **何も入力せずに通り過ぎたら、何が起きるか** | | |
| **入力が競合したとき（直前の入力がまだ続いているとき）、どちらを取るか** | | |
| **成功したとき／失敗したとき、それぞれ何が返るか（音・画面）。何段階の言葉で返すか** | | |
| **操作の成否に許容の幅は何段階か。幅はどれだけか** | | |
| **外したとき、どちら向きに外したかを返すか** | | |
| **続けて操作を求めるとき、人が反応できる時間を空けているか** | | |
| **押し続ける操作は、始まり・続き・終わりのどれで判定するか。許容はどれだけか** | | |
| **判定に関わる操作が、プレイヤーに見えているか** | | |
| **返しの音が、背景の音に埋もれないか** | | |
| **環境による遅れを見込むか** | | |

> **正しく操作したときの仕様は全員が書くが、外したとき・空振りしたとき・
> 何もしなかったときの仕様は落ちる。**

> **後ろの7問は、そのゲームに要らないことがある。**
> 要らないと決めたら〔このゲームには要らない〕の印を付ける
> （`templates/sheets/README.md`「欄の三つの状態」）。
> **問いの側に「〜なら」の条件を付けない。**条件で配らないと、落ちたことが見えない。

> **「人が反応できる時間」は、ゲーム側の値ではなく人の側の値。**
> 実測で 50〜200ms の幅があった（fishing-inc）。**幅の遅い端で成立するかを見る。**
