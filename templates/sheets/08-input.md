# 08 入出力

**C. 入出力の設計の問いは、ここが正本。**flow.md 段階3のCは、この表を指している。

| 問い | 答え |
|---|---|
| **入力は何種類あるか**（押す、長押し、ドラッグ、キー） | |
| **何を押すと何が起きるか。**操作の一覧 | |
| 待ち時間や演出のあいだ、操作を受け付けるか | |
| **絶対に止めてはいけない操作はどれか**（頻度の高いものは止めると累積で効く） | |
| 間違えて押したときに取り返しはつくか | |
| **判定や当たりの外で入力したら、何が起きるか** | |
| **何も入力せずに通り過ぎたら、何が起きるか** | |
| **入力が競合したとき（直前の入力がまだ続いているとき）、どちらを取るか** | |
| **成功したとき／失敗したとき、それぞれ何が返るか（音・画面）** | |

> **正しく操作したときの仕様は全員が書くが、外したとき・空振りしたとき・
> 何もしなかったときの仕様は落ちる。**
