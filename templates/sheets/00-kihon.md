# 00 基本

> **このシートを最初に埋める。**
> 答えによって、次に配られるシートが決まる。
> **空欄のまま先へ進まないこと。**

| 問い | 答え |
|---|---|
| 面白さの核（一文で） | |
| **どうなっていれば面白いはずか**（仮説。「〜のとき、〜すると、〜になる」の形） | |
| **通しで何時間遊ぶ想定か** | |
| **一回の繰り返しは何秒か** | |
| **終わりはあるか。あるなら何をしたら終わりか** | |
| **新しいものが順に出てくるか** | |
| **尽きるものはあるか**（回数が決まっているもの） | |
| 何を増やすゲームか | |
| プレイヤーが直接できることは何か | |
| プレイヤーができないことは何か | |
| **どんなジャンルか。掛け合わせなら全部書く** | |
| **画面は何種類あるか** | |
| **数値で調整するものはあるか** | |
| 何で作るか | |

## 配布の規則

| 埋めた答え | 配られるシート |
|---|---|
| **常に** | 01-core-loop.md |
| **常に** | 08-input.md |
| 通しが1時間を超える | **02-meta-loop.md** |
| 新しいものが順に出る | **03-beat-chart.md** |
| 尽きるものがある | **04-arc.md** |
| 終わりがある | **05-endgame.md** |
| 画面が2種類以上 | 06-screens.md |
| 数値で調整するものがある | 07-tunables.md |
| **ジャンルを書いた** | **書いたジャンルのジャンルシート**（`genre/`）。書いた数だけ |
| 通しが1時間を超える | **09-loop-chart.md**（02のメタループが10回以上巡るなら必ず） |

> **テトリスのようなゲームなら 01 と 08 だけでよい。**
> 全部を書かせる形にすると、短いゲームで邪魔になる。
