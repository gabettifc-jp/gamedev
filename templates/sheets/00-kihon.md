## 配布の規則

| 埋めた答え | 配られるシート |
|---|---|
| **常に・いちばん先** | **10-prototype.md**（一回。これを抜けるまで下は配らない） |
| **常に** | 01-core-loop.md |
| **常に** | 08-input.md |
| 通しが1時間を超える | **02-meta-loop.md** |
| 新しいものが順に出る | **03-beat-chart.md** |
| 尽きるものがある | **04-arc.md** |
| 終わりがある | **05-endgame.md** |
| 画面が2種類以上 | 06-screens.md |
| 数値で調整するものがある | 07-tunables.md |
| **ジャンルを書いた** | **書いたジャンルのジャンルシート**（`genre/`）。書いた数だけ。<br>**一回の段では、相場の分野1〜4だけを見る**（入力と判定／返し／見せ方と予告／構造） |
| 通しが1時間を超える | **09-loop-chart.md**（02のメタループが10回以上巡るなら必ず） |

> **テトリスのようなゲームなら 01 と 08 だけでよい。**
> 全部を書かせる形にすると、短いゲームで邪魔になる。
