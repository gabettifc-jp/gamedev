# 02 メタループ

**コアループの外側にある「なぜ繰り返すのか」の理由。何層あってもよい。**

各層について、次を埋める。**層の数だけ繰り返す。**

## 層（　　　　　）

| 問い | 答え | 根拠 |
|---|---|---|
| この層で、プレイヤーは何を目指すか | | |
| **一周（この層が一巡）は何分か** | | |
| 一巡すると何が変わるか | | |
| **一巡すると何が消えて、何が残るか** | | |
| **この層は何回巡ると尽きるか。尽きないか** | | |
| 尽きるなら、尽きた後は何の層が動くか | | |

## 層の一覧

| 層 | 目指すもの | 一巡の長さ | 何回で尽きるか |
|---|---|---|---|
| コア | | 秒 | 尽きない |
| メタ1 | | 分 | | |
| メタ2 | | 分〜時間 | | |

> **通しの時間を、層の長さと回数で割り算して確かめること。**
> 合わないなら、どこかの層が足りないか、多すぎる。
