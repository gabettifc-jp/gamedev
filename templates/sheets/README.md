# templates/sheets/

**空欄のあるシート。**項目を並べるだけでは守れなかったので、埋める形にした。

## 使い方

1. `00-kihon.md` を写して埋める
2. その答えで配られたシートを、順に埋める
   （**ジャンルシートも同じように埋める。**`genre/` にある）
3. **すべてのシートに空欄が無くなったら、段階3は終わり**

手で書いてもよいし、道具を使ってもよい。

## 道具（`tools/sheets.html`）

開き方は二つある。

### 1. ファイルに保存する（おすすめ）

```
node tools/serve.mjs ../fishing-inc/sheets
```

置き場を指定して立ち上げ、出てきた `http://127.0.0.1:5173/` を開く。
**書き込んだ内容が、その場所の `00-kihon.md` 〜 `09-loop-chart.md` にそのまま保存される。**

- 置き場が無ければ作る。空なら空のシートから始まる
- 書き込むたびに保存する（0.4秒ほどまとめてから）。左下に「保存した」と出る
- 開き直すと、置き場のファイルから読み直す
- 港を変えるには `--port=5199`
- `127.0.0.1` にだけ開く。指定した置き場の外は読み書きしない

### 2. ダブルクリックで開く

`tools/sheets.html` をそのまま開く。**サーバは要らない**が、
**ファイルには保存されない**（ブラウザのなかに残るだけ）。
書き出しボタンで markdown を出し、自分で貼り付けて保存する。

- 10枚を表で出し、**空欄に直接書き込める**。空欄は薄い黄色で、埋めると消える
- 左の一覧に**埋まり具合**（「3／10」）が出る
- `00` を埋めると、**配布の規則どおりに一覧が絞られる**。
  配られないシートは暗くなるが、押せば見られる
- **書き出す**を押すと、この `templates/sheets/` と同じ形の markdown が出る。
  10枚まとめてと、1枚ずつの両方
- 書いた markdown を貼れば**読み込める**。途中から続けられる
- 書いた内容は**ブラウザに残る**。閉じて開き直しても消えない
- `02` の層、`03` の時間の区切りと種類、`07` のつまみ、`09` の周と決めることは、**行を足せる**。
  行を足せる表は、あらかじめ文字が入っている欄も書き換えられる（既定値のつもり）

### 図（表に入れると、その場で変わる）

| シート | 図 | 何が見えるか |
|---|---|---|
| `02` | **層の帯** | 層ごとに、通しのどこまで届くか。**白い部分がそのまま穴** |
| `03` | **強度のグラフ** | 時点ごとの強度を棒で。単調・空白・終盤が最大、を自動で言う |
| `07` | **曲線** | 指数で伸びるものを対数目盛りで重ねる。交差する点と跳ねる点が見える |

**図は表の写し。**図の側では編集しない。

### つじつま（左の一覧の下）

シートをまたいで計算し、合わなければ赤くする。

- 通しの時間 … 02の（一巡の長さ×回数）の合計 ≒ 00の「通しで何時間」
- 一巡の中身 … 02のメタ1の一巡 ÷ 01の「一回は何秒か」＝ 一巡あたりの回数
- ビートチャートの全長 … 03の最後の時点 ≒ 00の「通しで何時間」

計算に要る欄が空なら「計算できない（◯◯が空）」と出る。黙って何も出さないことはしない。

> 道具のなかにシートの中身が写してある（`file://` では読み込みができないため）。
> **シートを直したら、道具のなかの写しも直すこと。**

> **ジャンルシート（`genre/`）は、まだ道具に載っていない。**
> 枚数が可変で、保存先の名前が `00`〜`09` の固定の並びから外れるため。
> **いまは手で書く。**

## 一覧

| シート | いつ配られるか |
|---|---|
| `00-kihon.md` | 最初に必ず |
| `01-core-loop.md` | 常に |
| `08-input.md` | 常に |
| `02-meta-loop.md` | 通しが1時間を超える |
| `03-beat-chart.md` | 新しいものが順に出る |
| `04-arc.md` | 尽きるものがある |
| `05-endgame.md` | 終わりがある |
| `06-screens.md` | 画面が2種類以上 |
| `07-tunables.md` | 数値で調整するものがある |
| `09-loop-chart.md` | 通しが1時間を超える（メタループが10回以上巡るなら必ず） |
| `genre/*.md` | **00でジャンルが挙がったとき。**挙がったジャンルの数だけ |

`spec.md` / `checklist.md` / `prompt.md` / `check.md` は、これまでどおり使う。
シートは仕様書を書く前の工程で、`spec.md` はその結果を書き留めるところ。
