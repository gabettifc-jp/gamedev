| 02「**一巡すると何が変わるか**」 | **恒久ボーナスに毎周ロックをかける作りがある。**プレステージ100を持っていても初期状態では一部しか効かず、毎周アップグレードを買って解放する（Cookie Clicker） | 〔攻略〕 | 周の序盤に目標が無くなる。貯金がそのまま効くと、始めた瞬間から中盤になる |
| 02「**この層は何回巡ると尽きるか。尽きないか**」 | **尽きない。ただし周の長さを揃えない。**所持数が300・400・500個に届いた瞬間に倍率がかかる作りにすると、そこで買い物が一気に進む塊ができる。モデルの実例では120分の長い周が、500個目の16倍で破れた | 〔Kong〕 | 周が等間隔になり、停滞が単調になる |
| 01「**それがもらえたと、画面のどこで分かるか**」 | **リセットの前に、押すと何が起きるかを具体的な数字で見せる。**「転生後は木こりの稼ぎが2.3倍になります」の形。**リセットが損ではなく報酬に見える** | 〔開発者〕 | **リセットが損に見えて、押されない** |
| 00「**新しいものが順に出てくるか**」 | **複雑さは段階的に開く。**要素を全部見せると圧倒される。節目ごとに開く形にすると、それ自体が中盤の「解放の瞬間」になる | 〔開発者〕 | 最初に全部見えて圧倒される |
| 06「**常に見えていなければならない数値は何か**（所持金、残量、進み具合）」 | **大きい数字の表記を一つに決めて、混ぜない。**短縮（1T）／科学表記／専用の名前のどれか。混ぜると壊れる ── **1×10^24 の次が 10×10^25、100×10^26 になっていた実例がある** | 〔講評〕 | **桁が読めなくなる。**表記がおかしいと言われる |

| 05「**勝ちは何か。負けはあるか**」 | 〔相場が取れなかった〕終わらせ方の相場は出てこなかった。**尽きない前提の作りが多く、終わりを置いた例が拾えていない** | ─ | 終盤に目標が無くなる |

| 01「**それがもらえたと、画面のどこで分かるか**」（買ったとき） | **取ると何がどれだけ上がるかを、具体的な数で出す。**「クリックが毎秒X回増える」「毎秒X個増える」の形。<br>**「アップグレードを買っても、その買い物の効果が測れない」という文句がジャンルの定番になっている**〔講評〕。<br>**恒久の強化だけでなく、毎周買う道具にも同じことが要る**〔実測〕。<br>**「効率が何倍になるか」は、腕を勘定に入れずに出す**──入れると買い物どうしを比べられなくなる〔実測〕。<br>**倍率が付かない買い物が在ってよい。**付かないこと自体が「そういう種類の強化だ」を伝える〔実測〕 | 〔講評〕〔実測〕 | **何を取ればいいか分からない。**「何取ったら何がどれだけ上がるのかわからない」〔実測〕 |
| 08「**何を押すと何が起きるか。**操作の一覧」（自動化） | **自動化は入切できるのが相場。**個別の入切と、**全部まとめて入切**の二段を持ち、押しやすい場所に置く（キー一つでも切れる）〔AD〕 | 〔AD〕 | **取り消せない自動化になり、貯めて大きいものを買う戦略が消える**〔実測〕 |

| 02「**一巡すると何が変わるか**」（恒久の強化の中身） | **「開く」ものと「数が上がる」ものの比を見る。**正典8本の共通項では **Optimization Problems（資源配分の最適化）が High-Value**、**Fast Numeric Growth と Automation は Low-Value**。中心概念は **unfolding**（新しい仕組みを定期的に開く）〔Paper Pilot〕。<br>**「同じものを買い続けるのは a chore」**、**「N倍になり費用もN倍になるだけの購入は水増し」**〔Paper Pilot〕。<br>**「実質的な資源は『起こしたブレイクスルーの数』」**〔清水〕 | 〔Paper Pilot〕〔清水〕 | **数が上がる段ばかりになる。**一本目は45段のうち**開くのが7段（15%）**だった〔実測〕 |
| 06「**一番よく見る画面には、何がどこに置いてあるか。**上・下・左・右・中央に、それぞれ何があるか」（強化の一覧） | **取るべき順を一覧の側で示すと、最適化問題が「指示の実行」に落ちる。**〔Paper Pilot〕は *Following Instructions*（攻略どおりに進む一本道）を**「内容ではない」**と名指ししている。**選ばせたいなら、順を教えない。教えるなら、選ばせることを諦めたと認める** | 〔Paper Pilot〕〔実測〕 | **一覧が助言になるほど、遊びは減る。**一本目は「値段の順＝取るべき順」を決にしたうえ、**次に取るものを金色で囲む目印まで足した**〔実測〕 |
| 00「**新しいものが順に出てくるか**」（強化が湧く条件） | **値段だけでなく「所持数」で湧かせる型がある。**Cookie Clicker は 1 / 5 / 25 / 50 / 100 / 150 / 200 個で次の段が現れる。**「25個買え」は上限ではなく、次の褒美の位置**として働く〔Cookie〕。<br>**★"Own N" の N は「遊んで増える数」である。**リセット回数で開かせる型は、**相場に一件も無い**〔実測〕 | 〔Cookie〕〔実測〕 | **強化が値段でしか開かなくなる。**数え上げの軸（集める・釣る）があっても、そこに褒美が繋がらない。<br>**★リセット回数で開かせると、開けるためだけにリセットを回す時間ができる。**一本目で**八周ぶん、投数0**になった〔実測〕。<br>これは同じ資料が「内容ではない」と名指ししている *Mindless Repetition*／*Idle Waiting* そのもの |

## 2. インクリメンタル固有の問い

| 問い | 答え | 相場 | 外すと何が起きるか |
|---|---|---|---|
| **最初の報酬までは何分か** | | **最初の報酬ループで生きるか死ぬかが決まる。**理解できてから報われるまでの間を詰める。最初の伸びを早くして、手応えのある演出を付ける | **最初の1時間で離脱する。**掴む前に閉じられる |
| **放置（オフライン進行）はあるか。あるなら戻ったときにどう見せるか** | | **あるとは限らない。**Egg, Inc. は放置の影響を減らすため2時間で切っている。**無い作りに「放置できない」と文句が出た例がある。**入れるなら、戻ったときに適用するか捨てるかを選ばせる作りもある | 「放置ゲーなのに放置できない」と言われる／戻ったときに何が起きたか分からない |

> **「最初の報酬までは何分か」は、他のジャンルでも立つ問いかもしれない。**
> いまは 00〜09 に行き先が無いのでここに置くが、二本目で同じ問いが出たら汎用シートへ上げる。
