## 1. 相場（汎用シートの問いに対する、音ゲーの答え）

**一行めは、参照する問いを逐語で持つ。**
シートの問いを直したら、この列と突き合わせて、直す行を機械で見つける。

| どのシートの、どの問いか | 音ゲーでの相場 | 出どころ | 外すと何が起きるか |
|---|---|---|---|
| 08「**操作の成否に許容の幅は何段階か。幅はどれだけか**」 | 3〜5段。最高判定 ±15〜30ms（競技系）／±40〜67ms（緩め）。コンボが切れない下限は ±100ms前後 | 〔比較表〕〔RH〕 | 完璧が出せる気がしない |
| 08「**外したとき、どちら向きに外したかを返すか**」 | 最高判定とMISS以外の全判定で EARLY／LATE を出す | 〔RH〕 | **直しようがない。「正しいタイミングが分かりにくすぎる」** |
| 08「**判定や当たりの外で入力したら、何が起きるか**」 | **窓の外の入力は符号を消さない。**連打で先の符号が消える作りは **mashing** と呼ばれ、そう判断した判定を無視する仕組みを入れる。「完全な見逃しか、早い／遅いの窓内で押したときだけ消せ」 | 〔RH〕〔講評〕 | **「どんなに離れてても押せば次の符号が反応する」** |
| 08「**何も入力せずに通り過ぎたら、何が起きるか**」 | 見逃しとして失敗扱い | 〔講評〕 | 押さないほうが得になりうる |
| 08「**押し続ける操作は、始まり・続き・終わりのどれで判定するか。許容はどれだけか**」 | **始まりと終わりの両方で見るのが相場。**ただし終わりの見方は三通りに割れる。<br>**(a) 離しをもう一つの符号として数える**──押し始めと離しで**二回**判定し、早く離すと即座に外し一回ぶん〔IIDX〕。ScoreV2 も同じ形で、**離しの許容は押しの1.5倍広い**〔osu〕<br>**(b) 一つの判定の頭打ちにする**──胴の途中で離すと、その回の評価が**最下段に落ちる**（外しにはしない）〔osu〕<br>**(c) 罰を与えない**──早く離すと**得点が伸びなくなるだけ**で、外しにも連続の切れにもしない〔GH〕<br>**離しの許容は押しより緩いのが共通。**終点の判定は後ろに伸びていて、**早く離すほうが厳しい**〔スマホ音ゲー〕。<br>胴にも判定を置く作りもある（中間点が8分間隔でコンボが増える〔スマホ音ゲー〕／stable の osu! は100msごと〔osu〕）が、**触ってみると「押しているあいだ変化する演出」は六つ全部落ちた**〔実測〕。落ちなかったのは**弾けた大きさをそのまま保つ**形だけ | 〔IIDX〕〔osu〕〔GH〕〔スマホ音ゲー〕〔解説〕〔RH〕〔実測〕 | 長押しが単押しと同じになる |
| 08「**入力が競合したとき（直前の入力がまだ続いているとき）、どちらを取るか**」 | 〔相場が取れなかった〕定量・定性とも出てこなかった | ─ | 入力が競合して片方が死ぬ |
| 08「**続けて操作を求めるとき、人が反応できる時間を空けているか**」 | 定量値は出てこない。定性としては「符号どうしが読めなくなる詰め方をしない」〔解説〕。**長音の帯を離してよい位置で切らないと、離してから次を押す時間がゼロになる**（長音500ms・次の符号も500ms） | 〔解説〕〔実測〕 | **「長音のすぐ後に符号があるとどちらか押せない」** |
| 08「**成功したとき／失敗したとき、それぞれ何が返るか（音・画面）。何段階の言葉で返すか**」 | 打鍵音は必須に近い。無いと**「耳が聞こえないまま音ゲーをしているようだ」**〔講評〕。**符号そのものが反応する必要がある**──符号が消えるだけ、画面の隅に文字が出るだけでは足りない〔講評〕。判定の言葉は3〜5段〔比較表〕。**触って出した値は 2200Hz・35ms が出発点。1200／1600／2800／3200Hz、低い芯つき、和音、鳴らさない まで試して、どれも「マシ」どまりだった**〔実測〕。**★ここが、このシートでいちばん薄い。**通しを触った後の判定も「速さより先に、押した瞬間の気持ちよさを研究しよう」だった〔実測〕。**音の高さと長さの外に相場が要る**（立ち上がり、減衰、画面との同時性、指ごたえ）。まだ調べていない。**離した瞬間にも必ず何かが返る。**返し方は三通りに割れるが（上の「押し続ける操作」の行）、**黙っている作りは一つも無かった。**罰を与えない作りでさえ、**帯の色が黒く落ち、その楽器の音が止まる**〔GH〕 | 〔講評〕〔比較表〕〔実測〕 | **合っていることが分からない** |
| 08「**判定に関わる操作が、プレイヤーに見えているか**」 | 符号が来る線を固定で置く〔RH〕。**長音は「頭・胴・尾」の三つの部品で描くのが相場。**スキンの仕様が三枚を別々に持ち（頭 `H`／胴 `L`／尾 `T`）、**尾を用意しなければ頭を反転して尾に使う**──つまり**頭と尾は単押しと同じ絵**で、胴だけがその後ろに伸びる〔osu〕。胴は**判定線で切り取られていく**〔osu〕〔GH〕 | 〔RH〕〔osu〕〔GH〕 | いつ押すか分からない／**長音のどこで押すのか形に出ない** |
| 08「**返しの音が、背景の音に埋もれないか**」 | 合図の音が曲の音に近すぎると、いつ押すか分からなくなる。合図の音は全編で同一に保つ | 〔ETC〕 | 曲が合図を食う |
| 08「**環境による遅れを見込むか**」 | **ずれは三種類（音の出／画面の描画／入力）。**装置ごとに違うので自動では決まらず、ほとんどの音ゲーが起動時に較正を置く。**ブラウザの音は特に遅い** | 〔開発者〕 | 上手い人ほど「判定がおかしい」と言う |
| 01「**それがもらえたと、画面のどこで分かるか**」 | **押した瞬間に、符号そのものが反応する。**触って出した形は「短い符号と同じように一瞬ふくらんで戻る」。**押しているあいだ足すと嫌われる**（音・脈打ち・縁の光・保持の合図・帯が減る、六つ試して全部落ちた）〔実測〕 | 〔講評〕〔実測〕 | 押したか分からず、画面の隅を見続けることになる |
| 01「**一回は何秒か**」 | 始まりに準備の拍（カウントイン）を置く。〔相場が取れなかった〕拍数の相場は出てこなかった | ─ | 一つ目の符号を必ず落とす |
| 04「**難しさはどこで上がるか**」 | **速さで上げない。**速さで上げると、覚えたことの意味が消える | 〔解説〕 | 理不尽になる／格の差が伝わらない |

> 〔相場が取れなかった〕は「**調べたが無かった**」の印で、行が無いのとは別のこと。

## 2. 音ゲー固有の問い（汎用シートに行き先が無いもの）

**ここだけ、問いの形で持つ。**多くのゲームは「プレイヤーの操作」が基準なので問いが立たない。
**時間で進むゲームでしか意味をなさない。**

| 問い | 答え | 相場 | 外すと何が起きるか |
|---|---|---|---|
| **操作の要求は、何を基準に出るか（譜面は曲のどこに合うか）** | | **BPMが0.01ずれるだけで、曲の後半で目に見えてずれる**〔解説〕。**fishing-inc はここが空欄のまま作られ、譜面と曲が同期していなかった。**キーサウンド（曲を符号の断片に切る作り）を採らないと決めた理由がこれ〔実測〕 | 後半だけ合わなくなる。曲と結びついた作りが一つも採れなくなる |

> **「プレイヤーが調整した設定は保存されるか」は、00〜09 に行き先が無い。**
> 音ゲーでは較正の値がこれにあたる。`gamedev/open.md` を見よ。

## 3. 出どころの記号

| 記号 | 出どころ |
|---|---|
| 〔比較表〕 | コミュニティが作った、数十本の音ゲーの判定窓の比較表（ZIv フォーラム） |
| 〔RH〕 | Rhythm Horizon の公開仕様 |
| 〔講評〕 | itch.io のジャム作品に付いた遊んだ人の講評（複数件） |
| 〔開発者〕 | Rhythm Quest 開発日誌、Native Audio の音ゲー講座 |
| 〔ETC〕 | カーネギーメロン ETC「音ゲーの音の設計」 |
| 〔解説〕 | 譜面制作の解説サイト・用語集 |
| 〔osu〕 | osu!mania の公式wiki（判定の仕様、スキンの仕様） |
| 〔IIDX〕 | beatmania IIDX の攻略サイト iidx.org（チャージノート） |
| 〔GH〕 | Guitar Hero の有志wiki（長音・サステイン） |
| 〔スマホ音ゲー〕 | 国内スマホ音ゲーの解説記事（ロングノーツの判定） |
| **〔実測〕** | **手触りの見本を触って出した値**（fishing-inc／2026-08-20。`builds/` に六版） |

> **〔実測〕は、調べても出なかった相場が触ると出るときに使う。**
> 外から採った相場と、触って出した相場を、後から区別できるようにするため。

> **〔相場が取れなかった〕は出どころではなく印。**上の表の記号とは別もので、
> 調べたが相場が取れなかった欄に付く。まだ調べていない（行が無い）とは区別して読む。
