# 手つき：ポップな見下ろし

**スマホゲームの群れる見下ろし（明るい色・太い暗い輪郭・丸い塊）を、Canvas 2D の手描きで出すときの決まり。**
ゲームをまたいで効く。写して使う。走る版は `templates/tetsuki-pop.html`。

- 出どころ：spice-lanes の見本21〜23（2026-08-22）
- 調べたもの：`references/art-stylized.md`
- **一つ残らず、描いて・撮って・見て確かめた。**見ずに書いた決まりは一つも入れていない

---

## 0. この手つきを選ぶ前に

**シルエットを真っ黒に塗って、それが何か分かるか。**分からないなら、この先は全部無駄になる。

> 真っ黒のシルエットにして見分けがつかないなら、形の言語が失敗している。
> どれだけ質感を磨いても取り返せない
> ── https://nastyrodent.com/stylized-3d-characters-art-direction-principles/

---

## 1. 決まり（九条）

| | 決まり | 画面で何に見えるか |
|---|---|---|
| 1 | **形は楕円だけで組む。**多角形を使わない | 塊が丸く、柔らかく見える |
| 2 | **平らに見せたい面だけ、直線で引く。**丸い形から切り出さない | 甲板・机・床が平らに見える |
| 3 | **輪郭は外形に一本だけ。**太さは全部同じ、色は一つの暗い色 | 小さくしても形が残る |
| 4 | **面の中の帯には、輪郭を付けない** | 付けると外形の輪郭と重なって、太い黒い棒に見える |
| 5 | **面の上に、白い照りを一枚だけ** | 面が硬く、つやがあるように見える |
| 6 | **足元に、暗い楕円の影と、白い輪** | 地面から浮いて、どこに居るかが分かる |
| 7 | **色は要素ごとに二色（明・暗）だけ** | 安っぽくならず、うるさくもならない |
| 8 | **ゆっくり上下させる** | 止まっていると死んで見える |
| 9 | **顔をつける（丸窓・目でよい）** | 物でも生き物に見える |

2 と 4 は spice-lanes 見本23 で足した。
**1 だけを守ると、平らであるべき面までドームに見える。**

## 2. つまみ（数値は全部ここ）

写した先でも、この表の順にファイル先頭へ並べる。

| つまみ | 既定 | 動かすと |
|---|---|---|
| `OUT`（輪郭の色） | `#1a2028` | 明るくすると柔らかく、暗くすると硬くなる |
| `LW`（輪郭の太さ・基準の大きさに対する比） | `0.036` | 太いほど「シール」に寄る。細いと弱く見える |
| `SHEEN`（照りの濃さ） | `0.26` | 上げるとつやが強い。0.4を超えると白飛びして見える |
| `SHEEN_H`（照りの高さの比） | `0.30` | 面の上どのくらいを照らすか |
| `SHADOW`（足元の影の濃さ） | `0.26` | 濃いほど地面に近く、薄いほど浮いて見える |
| `SHADOW_W`（影の横幅の比） | `0.90` | 広いほど大きく見える |
| `RING`（足元の白い輪の濃さ） | `0.55` | 群れの中で自分を見失わないための輪。強くしすぎると主張する |
| `BOB_A`（上下の幅） | `0.5` | 大きいほど軽く見える |
| `BOB_HZ`（上下の速さ） | `2.2` | 速いほど落ち着かない |
| `DARK`（暗い側の色を作る倍率） | — | 要素ごとの二色目。明るい色から作る |

**数値をコードに直接書かない。**全部この表に出す。

## 3. 効かなかったこと（同じ道を二度歩かないため）

| やったこと | 結果 |
|---|---|
| 質感を16通り作って並べた | **効かない。**形が読めていないうちは、質感をいくら磨いても戻らない |
| 面を900→4,300に増やした | **効かない。**「小さい細部は、大きくて読みやすい一つにまとめる」の逆をやった |
| ポリゴンを640まで落とした | **「安っぽすぎる」**と返った。原因はポリゴン数ではなく、面の上に何も乗っていないこと |
| 甲板の帯に輪郭を付けた | 船体の輪郭と重なって、**太い黒い棒**に見えた（決まり4はこれで生まれた） |
| 白い照りを四角で乗せた | **シールが貼ってあるように浮いた。**照りは面の形に沿わせる |
| **描いたものを一度も見なかった（見本1〜20）** | **今日の外しの大半がここ。**撮って見れば、その場で分かった |

## 4. 使うときの手順

1. `templates/tetsuki-pop.html` を写して、つまみだけ書き換える
2. **描いたら、必ず撮って、自分で見る。**見ないで出さない
3. 小さくしたときにも見る。**地図の大きさと、引いたときの二つ**を並べて出す
4. 一度置いた見本は直さない。直したものは新しい名前で置く（`templates/mihon.md`）

### 撮って見る道具

```js
// shot.mjs — node shot.mjs <html の絶対パス> <png の絶対パス> [待ち ms] [幅] [高さ]
import { chromium } from 'playwright';
const [,, file, out, wait='900', w='1000', h='700'] = process.argv;
const b = await chromium.launch();
const p = await b.newPage({ viewport:{width:+w,height:+h}, deviceScaleFactor:2 });
await p.goto('file://'+file);
await p.waitForTimeout(+wait);
await p.screenshot({ path: out });
await b.close();
```

## 5. この手つきが向かないもの

- **ドット絵**。輪郭の太さを一定にできない
- **写実**。決まり3と7が真っ向から邪魔をする
- **細かい情報を詰める画面**（表・帳簿）。太い輪郭が場所を食う
